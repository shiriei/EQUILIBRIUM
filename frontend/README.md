# EQUILIBRIUM Frontend

This directory contains the React and Vite-based frontend for EQUILIBRIUM.

It is responsible for:
- Rendering 2D and 3D scientific simulations using Canvas, Three.js, RDKit.js, and 3Dmol.js.
- Providing forms for the student predict-before-experiment workflow.
- Displaying graphs and results using Chart.js.
- Communicating with the FastAPI backend.

**Note:** No scientific calculations or AI integrations are performed directly in the frontend.
